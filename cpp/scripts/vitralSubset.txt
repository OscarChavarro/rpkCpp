# Files of base/src/main that RenderPark takes from VITRAL unchanged (plan D1:
# a pinned source subset). base/ holds exactly these files and nothing else:
# RenderPark's own classes live in rpkBase/ and rpkOpenGL1/.
# scripts/vitralSubset.sh --check compares each with a VITRAL checkout byte for
# byte and fails on any file of base/src/main missing from this list;
# --refresh copies them from it.
# The list includes the environment/material files of plan step 2a
# (PhongLobe, PhongMaterial, ScatteringComponent, Texture, and their test
# base/src/test/phong_material_tests.cpp); for the step 4 replay, the
# environment/geometry/spatialIndex contract with its linear and binned SAH
# indexes, BinnedSahHierarchy, Ray, RaytraceStatistics, Boolean and AtomicLong
# (their test is base/src/test/spatial_index_tests.cpp); the grid port of
# step 4 item 3, GridSpatialIndex and SpatialGroupTree;
# and io/wrapper/FileUncompressWrapper.cpp with RenderPark's Logger::reportMessage
# calls, taken into VITRAL (which now compiles io/wrapper) in the base/rpkBase split.
# RenderPark's lineal algebra uses VITRAL's double precision Vector2Dd,
# Vector3Dd, Vector4Dd and Matrix4x4d (RenderPark's Vector2D, Vector3D,
# Vector4D and Matrix4x4 were removed, and later its use of the float variants
# Vector2Df, Vector3Df, Vector4Df and Matrix4x4f, which stay in the list because
# AlgebraPrimitives.cpp defines them), and io/wrapper/Vector3DPrinter, written
# for Vector3Dd in VITRAL, joined the list. RenderPark's Matrix2x2 moved into
# VITRAL as an immutable double affine transform, so io/wrapper/Matrix2x2Printer
# is compiled there and joined the list too. PlanarFace, the Phong material
# classes and KDTree compute in double; RenderPark's RpkRay gave way to Ray.
# RenderPark's Cie color space moved into VITRAL's common/color package, with
# its references to the bibliography, and joined the list.
# For the MGF reader, the parametric primitives Sphere, Cone (with Tube, whose
# washer lamina builds the open lamina of a cone), Torus and Prism joined the
# list with their exports to PolyhedralBoundedSolid and everything they
# include: the Geometry / Solid / Volume hierarchy, the ray query elements
# and the boundary representation kernel (Euler operators and validation).
# The convex polygon clipper of [SUTH1974b] (geometricProcessing/convexPolygonClipper)
# and the polygon scan converter and visibility buffer of [HECK1990] and
# [BEKA1997] (render/raster/polygonScanConverter) moved from rpkBase into VITRAL.
