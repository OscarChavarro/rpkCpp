# Files of java/base/src/main that the Java port takes from VITRAL's Java port
# unchanged (plan D1: a pinned source subset). base/ holds exactly these files
# and nothing else: RenderPark's own classes live in rpkBase/ and rpkOpenGL1/.
# scripts/vitralSubset.sh --check compares each with a VITRAL checkout (its
# java/base/src/main) byte for byte and fails on any file of base/src/main
# missing from this list; --refresh copies them from it.
# Pin: VITRAL 9c443919 (Java port: lineal algebra on single precision; the
# environment/material classes of plan step 2a, the
# environment/geometry/spatialIndex contract with its linear, binned SAH and
# grid indexes, BinnedSahHierarchy, Ray and RaytraceStatistics), plus the
# classes taken into VITRAL's Java port in the base/rpkBase split:
# common/memoryManagement/MemoryPool and io/wrapper/FileUncompressWrapper,
# PipeInputStream, PipeOutputStream and StreamOpenMode.
# RenderPark's lineal algebra uses VITRAL's Vector2Df, Vector3Df, Vector4Df,
# Matrix4x4f and Matrix2x2 (RenderPark's Vector2D, Vector3D, Vector4D,
# Matrix4x4 and Matrix2x2 were removed), with io/wrapper/Vector3DPrinter and
# Matrix2x2Printer. The C++ subset (cpp/scripts/vitralSubset.txt) also lists
# the java/* emulation classes and AlgebraPrimitives.cpp, which have no Java
# file; this list adds the Java-only classes the subset depends on (Entity,
# EntityEvent, EntityListener, FundamentalEntity, ModelElement,
# BinnedSahHierarchyNode, BinnedSahLeafVisitor, BinnedSahStoppingLeafVisitor,
# _BinnedSahBox, _BinnedSahBuildTask,
# ScatteringArithmetic).
