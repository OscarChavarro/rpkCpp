# Files of java/base/src/main that the Java port takes from VITRAL's Java port
# unchanged (plan D1: a pinned source subset). base/ holds exactly these files
# and nothing else: RenderPark's own classes live in rpkBase/ and rpkOpenGL1/.
# scripts/vitralSubset.sh --check compares each with a VITRAL checkout (its
# java/base/src/main) byte for byte and fails on any file of base/src/main
# missing from this list; --refresh copies them from it.
# Pin: VITRAL 20e67173 (Cpp port: operations to support radiosity on double
# precision arithmetic) plus the matching uncommitted Java port changes of
# vitral/java: the operations of 20e67173 in Vector3Dd (lengthSquared,
# manhattanLength, distance, distanceSquared, multiplyByInverse, normalized,
# dominantAxis, component) and Vector2Dd (subtract, lengthSquared), and
# KDTree, KDQuery, KDTreeAdapter, Matrix2x2, PlanarFace, PhongLobe,
# PhongMaterial, ScatteringArithmetic, ScatteringFrame, SurfaceShadingPoint,
# Texture and Vector3DPrinter moved from float to double in place.
# RenderPark's lineal algebra uses VITRAL's double precision Vector2Dd,
# Vector3Dd, Vector4Dd, Matrix4x4d and Matrix2x2 (the float classes stay in
# the list as dependencies of the subset only), VITRAL's Ray
# (environment/geometry/element/Ray, RenderPark's own Ray was removed) and
# VITRAL's Cie color model (RenderPark's static Cie was removed). The MGF
# reader builds its primitives with VITRAL's Sphere, Cone, Torus, Tube and
# Prism exported to a PolyhedralBoundedSolid, so this list takes the closure of
# those classes (environment/geometry/volume and its polyhedralBoundedSolid
# kernel, surface/polygon, environment/scene, media, processing and their
# dependencies, computed with scripts/vitralClosure.py). The C++ subset
# (cpp/scripts/vitralSubset.txt) also lists the java/* emulation classes and
# AlgebraPrimitives.cpp, which have no Java file; this list adds the Java-only
# classes the subset depends on (Entity, EntityEvent, EntityListener,
# FundamentalEntity, ModelElement, BinnedSahHierarchyNode, BinnedSahLeafVisitor,
# BinnedSahStoppingLeafVisitor, _BinnedSahBox, _BinnedSahBuildTask,
# ScatteringArithmetic).
